# 个人博客开发流程

> 基于 Next.js 全栈的动态个人博客，支持文章展示、评论系统和后台管理

---

## 一、需求分析与设计

### 1.1 需求沟通

通过 Brainstorming Skill 逐步明确需求：

| 问题 | 结论 |
|------|------|
| 博客类型？ | 混合型（技术 + 生活） |
| 静态还是动态？ | 动态博客 |
| 技术栈？ | Next.js 全栈 |
| 核心功能？ | 文章展示、评论系统、后台管理 |
| 评论方案？ | 自建评论系统 + 审核机制 |

### 1.2 视觉设计

使用 Visual Companion 在浏览器中展示布局方案：

- **首页布局**: 卡片网格（三列响应式）
- **文章页**: 左侧内容 + 右侧边栏
- **评论位置**: 文章底部
- **主题**: 亮色/暗色双模式切换

### 1.3 最终技术选型

| 项目 | 选择 |
|------|------|
| 框架 | Next.js 16 (App Router) |
| 数据库 ORM | Prisma 7 + SQLite |
| 样式方案 | Tailwind CSS v4 + shadcn/ui |
| 认证 | NextAuth.js v4 (Credentials) |
| Markdown | react-markdown + remark-gfm + rehype-highlight |
| 主题切换 | next-themes |
| 图标 | lucide-react |

## 三、执行过程

使用 Subagent-Driven Development Skill 逐任务执行，每个任务经过：

```
实现子 Agent → Spec 合规审查 → 代码质量审查 → 进入下一任务
```

### 3.1 关键适配：Next.js 16

实际安装的是 Next.js 16，与计划中的 Next.js 14 有较大差异：

```diff
- // 旧: middleware.ts
- export { default } from "next-auth/middleware"
+ // 新: proxy.ts (Next.js 16 重命名)
+ export async function proxy(request: NextRequest) {
+   // ...
+ }

- // 旧: params 直接使用
- export async function GET(req, { params }) {
-   const { slug } = params
+ // 新: params 是 Promise
+ export async function GET(req, { params }: { params: Promise<{ slug: string }> }) {
+   const { slug } = await params
+ }
```

### 3.2 关键适配：Prisma 7

Prisma 7 使用全新架构：

- Generator 变为 `prisma-client`（非 `prisma-client-js`）
- 需要 `@prisma/adapter-libsql` 驱动适配器
- 配置移至 `prisma.config.ts`
- Seed 配置在 `prisma.config.ts` 中而非 `package.json`

### 3.3 关键适配：Tailwind CSS v4

- 没有 `tailwind.config.ts`，配置 CSS 驱动
- Typography 插件使用 `@plugin "@tailwindcss/typography"` 引入
- shadcn/ui 使用 Nova 风格（基于 Base UI 而非 Radix）

## 五、数据模型

```prisma
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  password  String       # bcrypt 加密
  name      String
  createdAt DateTime @default(now())
}

model Post {
  id         Int       @id @default(autoincrement())
  title      String
  slug       String    @unique    # URL 标识
  content    String               # Markdown 内容
  excerpt    String               # 摘要（自动截取前200字）
  coverImage String?              # 封面图
  published  Boolean   @default(false)
  tags       String    @default("")  # 逗号分隔
  createdAt  DateTime  @default(now())
  updatedAt  DateTime  @updatedAt
  comments   Comment[]
}

model Comment {
  id        Int       @id @default(autoincrement())
  postId    Int
  post      Post      @relation(fields: [postId], references: [id], onDelete: Cascade)
  author    String
  email     String?
  content   String
  approved  Boolean   @default(false)  # 审核状态
  parentId  Int?
  parent    Comment?  @relation("CommentReplies", fields: [parentId], references: [id])
  replies   Comment[] @relation("CommentReplies")  # 嵌套回复
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
}
```

## 六、认证流程

```
用户访问 /admin/*
  ↓
proxy.ts (Next.js 16 中间件替代) 检查 JWT Token
  ↓
未登录 → 重定向到 /admin/login
已登录 → 放行，显示管理页面

登录流程：
  输入邮箱密码 → POST /api/auth/callback/credentials
  → NextAuth 验证凭据 → 生成 JWT → 写入 Cookie
  → 跳转到仪表盘

种子账号：admin@blog.com / admin123
```

---

## 七、评论审核流程

```
访客提交评论
  ↓
API 检查内容是否含链接
  ├─ 含链接 → approved = false
  └─ 无链接 → approved = false (默认需审核)
  ↓
前台显示"评论已提交，审核通过后将显示"
  ↓
管理员登录后台 → 评论管理 → 审核通过/删除
  ↓
通过后前台可见
```

## 八、部署说明

### 开发环境
```bash
cd my-blog
npm run dev          # 启动开发服务器
```

### 生产环境
```bash
npm run build        # 构建
npm start            # 生产模式启动
```

### 首次初始化
```bash
npx prisma migrate dev --name init   # 创建数据库表
npm run seed                          # 创建管理员账号
```

### 建议部署方式
- VPS + PM2 进程管理，或
- Docker 容器化部署
